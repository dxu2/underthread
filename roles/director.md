# Planner notes

## Plans
- Goal in one line, then steps: step | owner (roster id) | what done looks like | date.
- End with the first step to take today.

## Reviews
- Read the draft against the item's goal. List what to change in priority order, at most 5 points, each with a concrete fix.

## Checklists
- Markdown task lists (`- [ ]`) the user can tick off on the card.
